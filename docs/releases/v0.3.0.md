# Release Notes: v0.3.0

**Release Date:** 2026-08-02

## Overview

PipelineConductor v0.3.0 publishes the `pipelineconductor` CLI as part of the repository, making it installable via `go install`. It also migrates the GitHub collector onto `gogithub` v0.17.0's version-isolated client and renames the dashboard dependency from `dashforge` to `uiforge`.

## Highlights

- **CLI now installable** - `pipelineconductor` (with the `check`, `scan`, `validate`, `remediate`, and `apply` subcommands) is now part of the published repository
- **Migrated off `go-github`** - `internal/collector.GitHubCollector` now wraps `gogithub`'s version-isolated `clientv1.Client`; `github.com/google/go-github` is now only a transitive dependency
- **Dashboard dependency renamed** - `dashforge` is now `uiforge` v0.4.0

## Installation

```bash
go install github.com/plexusone/pipelineconductor/cmd/pipelineconductor@v0.3.0
```

Or build from source:

```bash
git clone https://github.com/plexusone/pipelineconductor.git
cd pipelineconductor
go build -o pipelineconductor ./cmd/pipelineconductor
```

## Migration

No breaking changes. If you imported `github.com/plexusone/dashforge/dashboardir` directly, update the import to `github.com/plexusone/uiforge/dashboardir`.
